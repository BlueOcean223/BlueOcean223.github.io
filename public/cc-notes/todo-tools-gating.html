4. 官方说明#

tools-reference · Task tool availability：

Those models keep track of multi-step work without a written checklist, and the tools’ definitions and reminders take up context, so Claude Code leaves them out. Without them, Claude adds nothing to the task list while it works.

这些模型能跟住多步工作，不需要书面清单；工具的定义和提醒会占上下文，所以 Claude Code 把它们拿掉。没有这些工具时，Claude 工作时不会往任务列表里写任何东西。

Agent SDK · Todo tracking：

Claude tracks multi-step work without a written todo list, and Claude Code leaves the task-tracking tools out of sessions by default. You don’t need anything on this page for Claude to work through multi-step tasks on those models.

在这些模型上，Claude 不靠书面 todo 列表就能跟住多步工作，Claude Code 默认不把任务追踪工具放进会话。这些模型上走完多步任务，不需要本页的任何内容。

代码两处一起停：工具 isEnabled 为 false，task_reminder 先查 isTaskListToolsEnabled()。

例外：后台 / bgTakeover 始终给；SDK todoToolsOptIn()；未进门控表的模型走 v1/v2 互斥。逃生门：env + rosy_wren。

ENABLE_TODO_TOOLS=1

env 只把 isTodoToolsEnabled() 短路为 true。Task 四件套还要 v2 开着；TodoWrite 还要 ENABLE_TASKS=0。
