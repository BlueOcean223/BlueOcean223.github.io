一句话结论

Claude Code 是一套已经产品化、平台化的终端代理系统：它不只是“聊天 CLI + 一批工具”，而是把 REPL、headless SDK、slash 命令、模型主循环、工具协议、后台任务、多代理、MCP、插件、权限治理、远程桥接、记忆、设置托管、遥测和自研终端 UI 串成完整运行时。

运行链路总览

main.tsx
  ├─ entrypoints/init.ts        全局初始化、安全环境、遥测延后初始化
  ├─ setup.ts                   会话、cwd、worktree、hooks、memory、预取
  ├─ commands.ts / tools.ts     用户命令与模型工具集合
  ├─ QueryEngine.ts / query.ts  headless/SDK 与交互主循环
  ├─ components/App.tsx         AppState + Stats + FPS 顶层 Provider
  └─ bridge/* / remote/*        远程会话、远程控制、session ingress

最短阅读路径

只想快速理解整体，按这个顺序读源码入口：

  1. src/main.tsx — 启动入口与模式分流
  2. src/entrypoints/init.ts — 全局安全与遥测边界
  3. src/setup.ts — 会话准备、hooks、worktree
  4. src/context.ts — 系统与用户上下文来源
  5. src/query.ts — 模型循环、compact、工具执行、恢复
  6. src/QueryEngine.ts — headless/SDK 怎么包 query()
  7. src/Tool.ts + src/tools.ts — 工具协议与总表
  8. src/commands.ts — slash 命令总表
  9. src/state/AppStateStore.ts — 运行时状态控制面
  10. src/services/mcp/client.ts 与 src/services/api/client.ts
